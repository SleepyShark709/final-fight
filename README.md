# Final Fight V2

## 1. 游戏介绍

该游戏为一款横版 2d 游戏，游戏风格类似《合金弹头》《空洞骑士》《哈迪斯》等2d横版游戏，玩家控制游戏角色在横版地图进行闯关、收集、杀敌。并且支持升级系统、宠物系统、武器系统等功能。

## 2. 游戏玩法

| 按键 | 功能 |
|------|------|
| A / D | 左右移动 |
| K | 跳跃（短按小跳，长按满跳） |
| J | 攻击（支持连击） |
| L | 冲刺/闪避（带无敌帧，可穿越敌人） |
| U | 武器技能 |
| 1 / 2 / 3 | 切换武器（调试用：裂空剑 / 雷霆拳 / 追影弓） |
| I | 打开背包 |
| C | 数值面板 |
| P | 调试模式（碰撞框、FPS） |
| ESC | 暂停 |

## 3. 游戏机制

游戏采用 2d 物理引擎，玩家可以进行跳跃、攻击、闪避等操作。游戏具有真实的物理引擎，在游戏内会存在角色与场景之间的碰撞、摩擦、重力等物理效果。同时，游戏内还存在角色与角色之间的碰撞、摩擦、重力等物理效果。

## 4. 游戏目标

游戏为多关卡制，玩家需要通过每一关的挑战，最终到达终点。并且会在不同关卡中解锁玩家新的能力。

## 5. 更新日志

### v0.3.0 (开发中)

- **武器系统**:
    - 策略模式武器架构（WeaponBase），支持热切换
    - 裂空剑 — 3段连击 [1.0x, 1.2x, 1.5x]，技能：旋风斩（范围AOE）
    - 雷霆拳 — 5段快速连击，技能：闪电连击（3连锁定）
    - 追影弓 — 远程投射物，技能：箭雨（5箭扇形散射）
    - 投射物支持最大飞行距离限制和平台碰撞销毁
- **键位优化**:
    - L键专用冲刺，U键武器技能，解决键位冲突
    - 新增 TAB 地图、W 交互键位（预留）
- **核心系统**:
    - SaveManager — localStorage 永久存档（货币、升级、统计）
    - RunManager — 单次运行状态机（区域/房间/祝福/统计）
- **Bug 修复**:
    - 修复死亡/通关后 HP 显示不刷新的问题
    - 修复远程武器触发近战伤害判定的问题
    - 修复武器技能在冷却中仍改变状态的问题
