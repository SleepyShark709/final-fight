# Final Fight V2

## 1. 游戏介绍

该游戏为一款横版 2d 游戏，游戏风格类似《合金弹头》《空洞骑士》《哈迪斯》等2d横版游戏，玩家控制游戏角色在横版地图进行闯关、收集、杀敌。并且支持升级系统、宠物系统、武器系统等功能。

## 2. 游戏玩法

使用 AD 控制玩家左右移动，K进行跳跃，J进行攻击，I为打开背包，L为特殊技能操作。

## 3. 游戏机制

游戏采用 2d 物理引擎，玩家可以进行跳跃、攻击、闪避等操作。游戏具有真实的物理引擎，在游戏内会存在角色与场景之间的碰撞、摩擦、重力等物理效果。同时，游戏内还存在角色与角色之间的碰撞、摩擦、重力等物理效果。

## 4. 游戏目标

游戏为多关卡制，玩家需要通过每一关的挑战，最终到达终点。并且会在不同关卡中解锁玩家新的能力。
