# Final Fight V2 — Roguelike ARPG 全面升级设计文档

> 日期: 2026-03-04
> 状态: 已批准
> 目标: 将 Final Fight V2 从线性横版闯关升级为完整的 Roguelike ARPG

---

## 1. 核心循环

```
据点(Hub) → 选择进入回廊 → 战斗房间(5-8个) → Boss → 下一区域 → 死亡/通关 → 据点
```

- 3个区域，每区域5-8个房间 + 1个Boss
- 单次运行 15-25 分钟
- 死亡后回到据点，保留永久货币「记忆碎片」
- 死亡是进步，不是惩罚

### 房间类型

| 类型 | 图标 | 说明 | 比例 |
|------|------|------|------|
| 战斗房 | 剑 | 标准敌人遭遇 | 50% |
| 精英房 | 骷髅 | 更强敌人，必出祝福 | 15% |
| 商店 | 金币 | 购买祝福/物品 | 10% |
| 休息房 | 心 | 恢复生命值 | 10% |
| 事件房 | ? | 随机事件（赌博/诅咒/宝箱） | 10% |
| Boss房 | 皇冠 | 区域Boss | 每区域1个 |

### 房间生成

采用 JSON模板 + 动态实例化（非完全程序化）：

```typescript
interface RoomConfig {
  id: string;
  biome: 'cavern' | 'lava' | 'void';
  type: 'combat' | 'elite' | 'shop' | 'rest' | 'event' | 'boss';
  platforms: { x: number; y: number; width: number; tileCount: number }[];
  spawns: { type: string; x: number; y: number }[];
  decorations: { type: string; x: number; y: number; depth?: number }[];
  hazards: { type: string; x: number; y: number; width: number; height: number }[];
  exits: { position: 'left' | 'right' | 'top'; rewardType: string }[];
  size: { width: number; height: number };
}
```

每个区域预制 15-20 个房间模板，运行时随机抽取并动态创建Phaser对象。房间转场通过清除当前房间所有实体 + 加载下一模板实现。

## 2. 世界观：「无尽回廊」

一座不断变化的古代遗迹「回廊」，传说通关者可获得一个愿望。主角是一名失忆的战士，每次死亡后在回廊入口的篝火旁醒来，记忆逐渐恢复。

设定天然解释 Roguelike 机制：
- 重复挑战 = 回廊每次重组
- 永久成长 = 死亡中恢复力量（记忆碎片 = 升级点）
- NPC = 其他困在回廊中的挑战者
- Boss = 回廊的守护者

### NPC 系统（据点，v1.0共3个）

| NPC | 功能 | 叙事线 |
|-----|------|--------|
| 铁匠 | 武器升级/解锁 | 前回廊守护者，被击败后留在入口 |
| 药师 | 消耗品购买 | 用草药延续自己的生命 |
| 旅者 | 背景故事/提示 | 每次运行后讲述不同的传说 |

对话采用模块化系统：
- 每个NPC 30-50 条独立对话
- 根据玩家进度（死亡次数/到达区域/击败Boss）触发不同对话
- 使用优先级队列，确保重要对话优先
- 可随时跳过

## 3. 键位设计

解决冲刺与武器技能的键位冲突，完整键位表：

| 功能 | 键位 | 说明 |
|------|------|------|
| 左移 | A | 不变 |
| 右移 | D | 不变 |
| 跳跃 | K | 不变，支持短按小跳/长按满跳 |
| 普通攻击 | J | 不变，支持连击 |
| 冲刺/闪避 | L | 不变（高频操作，靠近攻击键） |
| 武器技能 | U | **新增**，J上方，右手食指自然上移 |
| 背包 | I | 不变 |
| 数值面板 | C | 不变 |
| 地图 | TAB | 新增，查看已探索房间 |
| 暂停 | ESC | 不变 |
| 调试 | P | 不变 |
| NPC交互 | W | 新增，据点场景中与NPC对话 |

键位布局逻辑：
- 左手 WASD 负责移动
- 右手 J/K/L/U 负责战斗（攻击/跳跃/冲刺/技能形成紧凑操作区）
- 功能键 I/C/TAB/ESC 为低频操作，不干扰战斗

## 4. 武器系统

### v1.0 三把核心武器

| 武器 | 类型 | 攻击特点 | 特殊技能(U键) | CD |
|------|------|----------|--------------|-----|
| 裂空剑 | 近战/平衡 | 3段连击，中速中伤害 | 旋风斩(范围AOE) | 5s |
| 雷霆拳 | 近战/速攻 | 5段快速连击，低单发高DPS | 闪电连击(锁定3连) | 4s |
| 追影弓 | 远程/精准 | 蓄力射击，精准打击 | 箭雨(范围AOE) | 6s |

### v1.1+ 后续武器（预留设计）

| 武器 | 类型 | 特殊技能(U键) |
|------|------|--------------|
| 铁壁盾 | 近战/防御 | 盾牌冲撞(击退) |
| 幽影链 | 中距/控制 | 束缚(定身AOE) |
| 炎爆杖 | 远程/法术 | 陨石(延迟高伤) |

### 技术实现：策略模式

武器作为可替换组件注入Player，不同武器修改：
- 攻击速度/帧数
- 攻击范围/碰撞框形状
- 连击段数和节奏
- 击退力度
- 特殊技能的冷却和效果

动画方案：角色身体统一动画 + 武器作为独立sprite跟随旋转/位移（Dead Cells方式），大幅降低美术成本。

## 5. 祝福系统（运行内临时强化）

### v1.0 三位神灵

| 神灵 | 主题 | 代表祝福 |
|------|------|----------|
| 炎神 | 持续伤害 | 攻击附带燃烧DOT |
| 雷神 | 连锁 | 攻击有几率连锁到附近敌人 |
| 冰神 | 控制 | 攻击减速敌人 |

### v1.1+ 后续神灵

| 神灵 | 主题 |
|------|------|
| 风神 | 机动（冲刺伤害/冲刺后加速） |
| 影神 | 暴击（背刺加成/暴击增强） |

### 祝福绑定位置（最多5个激活）

- 普通攻击(J) — 改变攻击附加效果
- 武器技能(U) — 改变技能附加效果
- 冲刺(L) — 冲刺附加效果
- 被动 — 全局增益
- 终极 — 需要2个同神灵祝福解锁

### 祝福品质

v1.0 仅2级：普通 / 强化（数值提升50%）。

### 选择机制

每次清房后显示3张祝福卡片，选1张。卡片显示：神灵图标、名称、品质、效果描述、绑定位置。

### 技术实现：装饰器模式

祝福作为修饰器包装攻击/技能函数，通过 `BlessingManager` 统一管理激活/移除。

## 7. 敌人设计

### 设计哲学

每个敌人测试玩家的一种核心能力。

### 区域1「石窟」敌人

| 敌人 | 行为原型 | 教玩家什么 |
|------|----------|-----------|
| 石骷髅 | 巡逻→追击→近战 | 基本战斗节奏 |
| 骷髅弓手 | 保持距离→射击 | 躲避弹幕、主动接近 |
| 石盾兵 | 正面格挡→反击 | 绕背攻击/等待破绽 |
| 蝙蝠群 | 飞行→俯冲 | 垂直战斗/精确攻击 |
| 炸弹虫 | 接近→自爆 | 距离管理/击退利用 |
| 精英骷髅 | 快速连击+闪避 | 高难度近战对决 |

### 区域2「熔岩殿堂」敌人

| 敌人 | 行为原型 | 新机制 |
|------|----------|--------|
| 熔岩史莱姆 | 分裂 | 击杀后分裂为2个小史莱姆 |
| 火焰法师 | 远程AOE | 地面火焰区域 |
| 熔岩巨人 | 高血量慢速 | 近身地震攻击 |
| 火蜥蜴 | 快速游击 | 扑击→撤退循环 |
| 岩石傀儡 | 投掷 | 扔石头远程+近身拍击 |

### 新敌人实现规范

继承 `Enemy` 基类，需实现：
1. `EnemyConfig` 数据在 `Constants.ts`（或新 `EnemyTable.ts`）定义
2. `playAttackAnimation()` 和 `updateAnimation()` 抽象方法
3. 如有特殊AI，重写 `updateAI()` 方法
4. 特殊机制通过额外状态枚举扩展（参考 `FlyingEnemy` 的 `FlyState`）

## 8. Boss 设计

### Boss 1：石窟守护者·巨石傀儡

**阶段1（100-60% HP）：** 3个基础攻击
- 横扫拳（地面，跳跃躲避）— 预告0.4秒
- 砸地（垂直，冲刺躲避）— 预告0.5秒
- 岩石投掷（远程，移动躲避）— 预告0.3秒

**阶段2（60-30% HP）：** 加速 + 新招
- 连续砸地（3连）— 预告0.4秒
- 岩石雨（多方向投射物）— 预告0.6秒

**阶段3（30-0% HP）：** 狂暴
- 所有攻击速度+50%
- 新招：地面裂缝从Boss脚下向外扩展（2秒扩展时间，多种安全区域）
- Boss短暂眩晕窗口（唯一安全输出时间）

### Boss 2：熔岩殿堂守护者·炎龙

**阶段1：** 火焰吐息 + 尾扫 + 召唤火蜥蜴
**阶段2：** 飞行阶段，空中俯冲 + 火球雨
**阶段3：** 全身燃烧（近身DOT），快速连续攻击

### Boss 设计原则

- 每个攻击都有明确预告动画（普通0.3-0.5s，重攻击0.6-0.8s，全屏1.0s）
- 难但公平：不依赖单一技能（如冲刺CD）来躲避攻击
- 击晕窗口：Boss完成特定连招后有短暂破绽
- 通关后解锁 Heat 系统（惩罚契约）供硬核玩家自定义难度

## 10. UI 设计

### 运行中 HUD（最简原则）

- **左上角**：HP条（心形图标 + 条状）
- **右上角**：金币数量
- **底部中央**：技能CD小图标（仅CD中显示）
- **屏幕中部偏右**：连击数字（弹出后2秒淡出）
- 祝福图标、区域/房间进度不常驻，仅在暂停菜单或房间转场时显示

### 关键UI面板

| 面板 | 触发 | 内容 |
|------|------|------|
| 祝福选择 | 清房后 | 3选1祝福卡片（神灵图标/名称/品质/效果/绑定位置） |
| 小地图 | TAB | 已探索房间 + 可选路径 |
| 暂停菜单 | ESC | 当前祝福列表 / 设置 / 退出运行 |
| 据点菜单 | NPC交互(W) | 升级/商店/对话 |
| 死亡结算 | 死亡时 | 击杀数/获取资源/最远到达/获得碎片 |

### 需要新增的反馈系统

| 系统 | 效果 | 优先级 |
|------|------|--------|
| 音效 | 攻击/受击/死亡/UI交互 | P0 |
| BGM | 区域音乐 + Boss战音乐 | P0 |
| 着地尘土 | 落地时脚下扬尘粒子 | P1 |

- 使用 jsfxr 程序生成像素风音效
- Phaser 3 内置 SoundManager（Web Audio API，Electron完全支持）
- BGM 使用免费像素风库（OpenGameArt）或 AI 生成
- 总计约 30-40 个独立音效文件

### 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 存档 | localStorage | Electron环境下可靠，无需后端 |
| 房间数据 | JSON模板 | 易于创建/编辑，支持热加载 |
| 武器系统 | 策略模式 | 武器作为可替换组件注入Player |
| 祝福系统 | 装饰器模式 | 祝福作为修饰器包装攻击/技能函数 |
| 状态效果 | Tick系统 | 每帧检查并应用/移除效果 |
| 音频 | Phaser SoundManager | 原生支持，无需额外库 |
