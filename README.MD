# Final Fight 2D 横版格斗游戏

一款基于 JavaScript 的 2D 横版格斗游戏，具有马里奥风格的地图滚动和格斗游戏元素。

## 功能特点

### 游戏机制

- **角色控制**：灵活的玩家控制系统，支持移动、跳跃和攻击
- **敌人 AI**：敌人会自动追踪玩家并进行攻击
- **地图滚动**：马里奥风格的侧向滚动地图，玩家移动时摄像机跟随
- **无限背景**：支持无限滚动的背景系统，带有视差效果
- **血量系统**：角色和敌人都有血量系统和受伤机制

### 技术实现

- **碰撞检测**：精确的碰撞检测系统，分别处理水平和垂直碰撞
- **地图渲染**：优化的地图渲染，仅绘制可见区域提高性能
- **摄像机系统**：智能摄像机跟随系统，保持玩家在屏幕最佳位置
- **调试工具**：丰富的调试信息和可视化工具，便于开发

## 操作说明

- **A/D** - 左右移动
- **K** - 跳跃
- **J** - 攻击
- **P** - 切换调试信息显示
- **Z/X** - 手动控制地图滚动（仅调试模式）
- **R** - 重置玩家位置和地图偏移

## 自定义与扩展

### 背景系统

游戏支持自定义背景图片和视差效果：

```javascript
backgroundSystem = {
  texture: game.textureByName("背景图片名称"),
  width: 背景宽度,
  height: 背景高度,
  parallaxFactor: 0.5, // 视差因子，值越小滚动越慢
};
```

### 地图扩展

地图支持通过复制基础地图段落来扩展：

```javascript
// 设置重复次数来控制地图长度
const repeatCount = 5; // 重复5次创建更长的地图
```

### 调试系统

调试模块提供以下信息：

- 玩家位置、速度和碰撞状态
- 地图偏移量和边界信息
- 摄像机跟随状态
- 敌人位置和行为

## 扩展开发

### 添加新角色

1. 创建角色图像资源
2. 扩展 `Character` 类并实现相关方法
3. 在场景中添加新角色实例

### 添加新地图

1. 设计地图数据数组
2. 更新 `GameTileMap` 类中的地图数据
3. 调整地图宽度和碰撞检测

### 添加新功能

1. 在相关类中实现新功能
2. 更新输入处理系统支持新操作
3. 更新画面渲染适配新元素

### 添加地图编辑器

地图编辑器支持以下功能：

- 点击地图块后，在画布添加当前选中的地图块数据
- 点击画布中的地图块可以进行删除
- 通过 json 获取当前地图数据信息
